# خريطة التحكم وأوامر Serial

يرسل `scripts/bridge.py` أحرف ASCII منفردة إلى firmware بسرعة 9600 baud. يستقبل الجسر يد تحكم عبر pygame ويعمل على USB Serial أو منفذ Bluetooth Classic SPP افتراضي. **الأرقام أدناه فهارس pygame تبدأ من صفر، وهي قيم ابتدائية؛ افحص يدك فعليًا بوضع `--probe-controllers` قبل توصيل طاقة المحركات.**

## الأزرار والمحاور

| دخل يد PS1/X360CE | فهرس pygame الافتراضي | الأمر | معنى الأمر |
|---|---:|---|---|
| العصا اليسرى X/Y | `0 / 1` | `F/B/L/R/S` | أمام/خلف/يمين/يسار/توقف بحسب الاتجاه الغالب. |
| زر Y/المثلث، كمُعدِّل | `0` مبدئيًا | مع R2 أو L2 | الفهرس يحتاج تأكيدًا من `--probe-controllers`؛ عدّله بـ`--spin-modifier-button N`. |
| R2 | `7` | `F` منفردًا؛ `C` مع Y | R2 وحده يطلب التقدم؛ مع Y يدور عكس عقارب الساعة. |
| L2 | `6` | `B` منفردًا؛ `c` مع Y | L2 وحده يطلب الرجوع؛ مع Y يدور مع عقارب الساعة. |
| L1 | `4` | `L` | تشغيل المحرك الأيسر وحده. |
| R1 | `5` | `R` | تشغيل المحرك الأيمن وحده. |
| Xbox A | `2` | `+` | زيادة مستوى السرعة درجتين. |
| Xbox X | `3` | `-` | خفض مستوى السرعة درجتين. |
| النقر على العصا اليمنى R3 | `11` | `H` | نمط صفير مزدوج. |
| العصا اليمنى X/Y | `5 / 2` | `1` إلى `4` | اتجاهات العصا الأربعة تختار أنماط البازر. |
| D-pad / Hat | `0` | `^`, `V`, `<`, `>` | حدث لحظي عند ضغط اتجاه جديد؛ اليسار/اليمين دوران زمني. |

إذا ضُغط R2 وL2 معًا يرسل الجسر `S` كإيقاف احترازي، سواء كان Y مضغوطًا أم لا. مع Y، يتقدم اختيار الدوران على الحركة العادية؛ ومن دون Y يعمل R2 للأمام وL2 للخلف. ضغط L1 وR1 معًا يرسل `S`. يمكن تعطيل أي زر افتراضي بتحديد فهرسه `-1`، واستخدام فهارس أخرى من نتائج الفحص.

## D-pad والزاوية

| الاتجاه | الحرف | سلوك firmware الحالي |
|---|---|---|
| أعلى | `^` | دفعة تقدم قصيرة PWM=255، لكنها تتطلب قراءة ميل تتجاوز +15° ومسافة أمامية صالحة لا تقل عن 15cm. |
| أسفل | `V` | دفعة رجوع قصيرة PWM=255، وتتطلب قراءة ميل أقل من −15°. |
| يمين | `>` | دوران زمني مبدئي 200ms. |
| يسار | `<` | دوران زمني مبدئي 200ms. |

مدة 200ms لا تعني أن الروبوت دار 45°؛ الزاوية الفعلية تتغير مع الجهد والمحركات والسطح والحمولة. عايرها بزيادات صغيرة والعجلات مرفوعة ثم اختبر في مساحة خالية. لا تستخدم أوامر الميل كوسيلة اتزان ذاتي.

## درجات السرعة

| الأمر | المعنى |
|---|---|
| `+` | زيادة مستويين، حتى 10. زر A الافتراضي. |
| `-` | خفض مستويين، حتى 0. زر X الافتراضي. |
| `*` | ضبط المستوى على 10. |
| `/` | خفض مستوى واحد. |
| 0 | PWM=0 وإيقاف المحركات. |

المستويات 1–10 تطلب PWM من 50 إلى 255 على ENA وENB. يرسل Arduino مثلًا `SPEED_LEVEL=6 PWM=163`. هذه القيمة الرقمية ليست قياسًا لسرعة RPM. يلزم إزالة جسري ENA/ENB في لوحة L298N كي تتحكم مخارج PWM بالتمكين.

## أوامر البازر

| الأمر | النمط |
|---|---|
| `H` | نغمتان قصيرتان. |
| `1` | نغمة زمور حديثة تقريبية. |
| `2` | تسلسل أحادي النغمة مستوحى من لحن تقليدي شائع. |
| `3` | نمط زمور منخفض/طويل. |
| `4` | تناوب نغمتين كصفارة تقريبية. |

هذه أنماط قصيرة لبازر أحادي النغمة وليست تسجيلات أو محاكاة لآلة موسيقية متعددة الأصوات. يدير العصا اليمنى النغمات، والنقر على R3 يرسل `H`.

## لوحة المفاتيح والربط اليدوي

أثناء تركيز نافذة الجسر: الأسهم للأمام/الخلف والدوران؛ `A/D` للمحرك الأيسر/الأيمن منفردًا؛ `Q/E` للدوران؛ وSpace للتوقف. يمكن إرسال أوامر لحظية من لوحة المفاتيح مثل `+ - * / H 1 2 3 4 < > ^ V`.

لتغيير أرقام الأزرار، استخدم `--help` بعد تشغيل وضع الفحص. مثال لربط زر إضافي بالمستوى الأعلى:

```bash
python scripts/bridge.py --port COM8 --bind='*=8'
```

## بروتوكول التوقف والاتصال

- أوامر الحركة المستمرة أحرف منفردة مثل `F` و`B` و`C` و`c` و`S`، بلا `\n` أو `\r`.
- يرسل الجسر حرف `Z` كل 100ms بوصفه heartbeat؛ لا يغير الحركة. إذا انقطعت نبضات الحياة أكثر من نحو 350ms، يوقف firmware المحركات.
- يطلب الجسر `S` عند حياد العصا أو فقدان تركيز النافذة أو الخروج الذي يستطيع اكتشافه. افصل طاقة المحركات يدويًا إذا حدث خلل.
- Serial Monitor على Uno يستخدم 9600 baud. أغلقه قبل تشغيل Python على المنفذ نفسه.
- أوامر Serial اليدوية مثل `F` ثم Enter لا تسلح watchdog ما لم ترسل `Z`؛ يبقى سلوك الطرفية مناسبًا للاختبار القصير مع رفع العجلات.
