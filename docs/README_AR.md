# فهرس وثائق المشروع

هذا المجلد يشرح مكونات الروبوت وطريقة التحكم والقيود المعروفة. ابدأ بالوثيقة المناسبة قبل تغيير الأسلاك أو تشغيل المحركات.

## ترتيب مقترح للقراءة

1. [التوصيلات والمكونات](WIRING_AND_HARDWARE.md): خريطة أرجل Arduino Uno، توصيل المحركات والحساسات، وملاحظات الطاقة. **هذه الخريطة خاصة بـUno وليست خريطة ESP32.**
2. [السلامة والاختبار](SAFETY_AND_TESTING.md): ما الذي لا يضمنه البرنامج، وماذا يجب اختباره والعجلات مرفوعة.
3. [خريطة التحكم](CONTROLLER_MAPPING.md): طريقة تحويل حركة الذراع ولوحة المفاتيح إلى أحرف Serial، وما ينفذه كل حرف فعلًا.
4. [البازر والنغمات](BUZZER_MUSIC_AR.md): توصيل البازر السلبي وأوامر النغمات وتردداتها ومددها كما هي في المصدر.

## الملفات الأساسية ذات الصلة

- `../src/main.cpp`: برنامج Arduino Uno، وهو المرجع النهائي لسلوك الأوامر والأرجل.
- `../scripts/bridge.py`: برنامج الكمبيوتر الذي يقرأ ذراع التحكم ويرسل الأوامر عبر USB.
- `../platformio.ini`: إعداد البناء والاختبار من PlatformIO.

## حدود هذه الوثائق

تصف الوثائق سلوك المصدر الموجود حاليًا، ولا تعني أن المكونات اختُبرت على روبوت فعلي. عند اختلاف وصف قديم عن الكود، يُراجع `src/main.cpp` ويُبلّغ عن التعارض قبل تشغيل العتاد. لا تخلط بين وجود حساس على الهيكل وبين تنفيذه برمجيًا؛ حالة كل مكوّن موضحة داخل وثيقة التوصيلات.
