# Notice

This standalone test project uses the Arduino-IRremote library version 4.7.1 through PlatformIO's library registry (`arduino-irremote/IRremote`). See the upstream project and license: https://github.com/Arduino-IRremote/Arduino-IRremote

The project sketch is a read-only IR receiver test. It does not contain robot motor-control code and does not transmit commands over Serial.
