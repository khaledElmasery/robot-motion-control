# Wokwi Simulation

`diagram.json` هو نموذج تحقق أولي للمسار Arduino/MPU6050/HC-SR04/LEDs. لا يُعد إثباتًا كهربائيًا كاملًا للمشروع، لأن L298N والمحركات وESP32 وIR وFD650 تحتاج نماذج/أجزاء متوافقة واختبار pin model. قبل اعتماد المحاكاة، طابقها مع `docs/README_AR.md` و`hardware/PINOUT_AND_POWER_AR.md` ولا تستخدمها بدل اختبار العتاد.
