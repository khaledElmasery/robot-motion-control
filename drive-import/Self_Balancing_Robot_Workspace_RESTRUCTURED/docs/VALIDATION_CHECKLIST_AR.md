# قائمة الفحص النهائية v3

## البناء والتنظيم

- [ ] `docs/README_AR.md` هو المرجع الشامل.
- [ ] `firmware/common/UnifiedBalance.ino` يترجم على Arduino وESP32 بإعدادين منفصلين.
- [ ] لا توجد ملفات `.err` أو `~` في النسخة النهائية المرجعية.
- [ ] Wokwi موسوم بوضوح كمحاكاة جزئية إن لم يحوِ كل المكونات.

## الكهرباء

- [ ] البطارية إلى L298N عبر مفتاح فصل.
- [ ] لا يوجد 12V على Arduino أو ESP32 أو MPU6050.
- [ ] GND مشترك في Bridge.
- [ ] UART يستخدم level shifter.
- [ ] HC-SR04 Echo مخفض إلى 3.3V على ESP32.
- [ ] مقاومة 220Ω لكل LED.

## الاتزان

- [ ] MPU6050 في مركز الهيكل.
- [ ] offsets مسجلة.
- [ ] Kp/Kd/Ki مضبوطة تدريجيًا.
- [ ] اختبار العجلات مرفوعة.
- [ ] اتجاه المحركات مطابق لاتجاه الميل.
- [ ] أمر الحركة ينتهي بعد 1000ms.
- [ ] HC-SR04 يغير setpoint دون قطع مفاجئ.

## الاتصال

- [ ] Bridge يمرر أوامر D-pad إلى Arduino.
- [ ] Bridge يمرر Telemetry من Arduino إلى Cloud.
- [ ] ESP32 STA يتصل بالسحابة، وAP يعمل عند الفشل.
- [ ] Dashboard يستقبل SSE.
- [ ] token غير افتراضي وHTTPS قبل النشر العام.
- [ ] IR codes ملتقطة من الريموت الحقيقي.
- [ ] FD650 مؤكد بالـdatasheet أو Logic Analyzer قبل تفعيله.
