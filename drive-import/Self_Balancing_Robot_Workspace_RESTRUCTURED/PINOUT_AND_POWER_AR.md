# Pinout والطاقة — الإصدار التنفيذي v2

> هذا الجدول هو المرجع الوحيد. لا تُستخدم أرجل من وثائق قديمة دون تحديثها هنا.

| الوظيفة | Arduino Uno | ESP32 Standalone | الملاحظة |
|---|---:|---:|---|
| MPU6050 SDA/SCL | A4/A5 | GPIO21/GPIO22 | I2C؛ VCC حسب الموديول وGND مشترك |
| MPU6050 INT | D2 | GPIO39 | محجوز للتوسع؛ القراءة الحالية polling |
| L298N IN1/IN2 | D6/D7 | GPIO32/33 | المحرك الأيسر |
| L298N IN3/IN4 | D8/D9 | GPIO25/26 | المحرك الأيمن |
| L298N ENA/ENB | D5/D10 | GPIO27/GPIO14 | PWM |
| IR OUT | D3 | GPIO2 | تُضاف خريطة الأكواد بعد التقاطها فعليًا |
| LEDs 1..4 | D11,D12,D13,D4 | GPIO4,16,17,23 | 220Ω لكل LED |
| HC-SR04 Trig/Echo | A0/A1 | GPIO5/GPIO34 | ESP32 Echo عبر مقسم جهد 5V→3.3V |
| MODE_PIN | — | GPIO35 | LOW=Bridge، HIGH=Standalone؛ لا تستخدم INPUT_PULLUP على GPIO35 |
| Bridge UART | — | UART2 RX=GPIO18 / TX=GPIO19 | استخدم محول مستويات؛ لا توصل TX Arduino 5V مباشرة إلى ESP32 |

## الطاقة والسلامة

- البطارية إلى مدخل 12V في L298N عبر مفتاح فصل؛ لا توصل 12V إلى Arduino أو ESP32 أو MPU6050.
- استخدم Buck مناسبًا، واربط GND الوحدات عند الحاجة.
- اختبر العجلات مرفوعة، ثم اختبر المسافة والـ emergency stop قبل وضع الحمل.
- لا يمكن اعتبار FD650 أو ريموت IR منفذين حتى تُقاس إشارات اللوحة وتُلتقط أكواد الريموت؛ الكود لا يخمّنها.
