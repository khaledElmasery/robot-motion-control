# ابدأ من هنا

المرجع الشامل والوحيد للمشروع هو `docs/README_AR.md`. يحتوي على المكونات، التوصيلات، الطاقة، الأنماط الأربعة، Firmware الموحد، Bridge، Cloud Backend، Dashboard، IR، FD650، Wokwi، مراحل التشغيل، والسلامة.

ابدأ بقراءة README ثم نفذ المراحل بالترتيب. لا توجد مجلدات `assets/original` أو نسخ أصلية مخفية داخل Workspace؛ أي ملف قديم أو `.err` لا يُعد مرجعًا للتوصيل. افصل البطارية دائمًا قبل نقل أي سلك من Arduino إلى ESP32.
