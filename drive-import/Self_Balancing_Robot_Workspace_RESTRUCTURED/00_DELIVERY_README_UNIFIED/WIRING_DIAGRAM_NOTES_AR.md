# ملاحظات مخطط التوصيلات المرجعي

تم بناء المخطط من الملفات المنشورة داخل Workspace، وبالتحديد `README_AR.md` و`PINOUT_AND_POWER_AR.md` و`UnifiedBalance.ino`. يعرض المخطط مسار Arduino + ESP32 Bridge بوصفه المسار الرئيسي، ويعرض Pinout ESP32 Standalone في لوحة جانبية منفصلة حتى لا تختلط الأرجل بين النمطين.

## مفتاح القراءة

الخط الأحمر للطاقة الموجبة، والأسود للأرضي المشترك، والبنفسجي لـI2C، والأرجواني لـUART Bridge، والأخضر/السماوي للمحركات، والبرتقالي للتحكم في L298N.

## ملاحظات سلامة مهمة

المخطط ليس مقياسًا ميكانيكيًا، ولا يثبت اتجاه دوران محركات الهيكل الفعلي. افصل البطارية قبل تعديل أي سلك. استخدم محول مستويات بين TX Arduino 5V وRX ESP32 3.3V، ومقسم جهد على Echo في ESP32. لا توصل بطارية المحركات مباشرة إلى Arduino أو ESP32 أو MPU6050. لا تشغل Arduino Bridge وESP32 Standalone في الوقت نفسه بنفس التوصيلات.

طرف IR يحتاج التقاط أكواد الريموت الحقيقي، وFD650 يحتاج Datasheet أو Logic Analyzer قبل إضافته إلى الدارة. اختبر العجلات مرفوعة، ثم عاير MPU6050 واضبط PID تدريجيًا قبل اختبار البطارية.
