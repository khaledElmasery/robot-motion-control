# جسر ذراع التحكم إلى Arduino

هذا المجلد يحتوي برنامجًا واحدًا للتشغيل على الكمبيوتر وملفًا لتثبيت اعتماداته.

| الملف | وظيفته |
|---|---|
| `bridge.py` | يقرأ أزرار ومحاور الذراع عبر pygame ويرسل أحرفًا إلى Arduino عبر USB Serial. لا يقود المحركات مباشرة. |
| `requirements.txt` | يثبت إصدارات `pygame` و`pyserial` اللازمة لتشغيل الجسر. |

## المتطلبات والتثبيت

- Python 3.10 أو أحدث.
- كابل USB متصل بلوحة Arduino، وتعريف Serial المناسب لنظام التشغيل.
- ذراع تحكم متوافق مع pygame اختياري؛ يمكن استخدام لوحة المفاتيح عندما تكون نافذة الجسر نشطة.

من جذر المستودع أنشئ بيئة مستقلة وثبّت الاعتمادات:

```bash
python3 -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r scripts/requirements.txt
```

## اكتشاف المنفذ والذراع

قبل الاتصال، اطبع المنافذ المتاحة ومعلومات أذرع التحكم:

```bash
python scripts/bridge.py --list-ports
python scripts/bridge.py --list-controllers
python scripts/bridge.py --self-test
```

الأمر `--self-test` لا يحتاج إلى Arduino أو ذراع. استخدم أسماء النتائج لتحديد المنفذ والجهاز بدل تخمينهما.

## التشغيل

السرعة الافتراضية 9600 baud، وهي مطابقة لإعداد firmware:

```bash
# Linux مثال
python scripts/bridge.py --port /dev/ttyACM0

# Windows مثال
python scripts/bridge.py --port COM3
```

أغلق Arduino Serial Monitor وأي برنامج آخر يستخدم المنفذ نفسه قبل تشغيل الجسر؛ عادةً لا يستطيع برنامجان فتح منفذ Serial واحد في الوقت نفسه.

## اختلاف الأذرع وربط الأزرار

أرقام المحاور والأزرار تختلف بين الشركات وأنظمة التشغيل. القيم الافتراضية للعصا اليسرى X/Y هي 0/1، ولليمنى 2/3، ورقم D-pad هو 0. عدّل المحاور بخيارات `--left-x` و`--left-y` و`--right-x` و`--right-y` عند الحاجة. يطبع `--list-controllers` عدد المحاور والأزرار للتشخيص.

لربط الأوامر الاختيارية بزر محلي استخدم صيغة `--bind=COMMAND=BUTTON`، مثل:

```bash
python scripts/bridge.py --port COM3 --bind=^=6 --bind=V=7 --bind=J=8 --bind=+=0 --bind=-=1 --bind='*=2' --bind=/=3
```

يجب أن يطابق رقم الزر ما يعرضه جهازك. راجع [جدول التحكم](../docs/CONTROLLER_MAPPING.md) لمعنى كل حرف وسلوكه.

## التعامل مع التوقف

يحاول الجسر إرسال `S` عند عودة التحكم إلى الحياد وعند حالات الخروج أو فقدان الإدخال التي يستطيع اكتشافها. لكن `S` **طلب توقف أفضل جهد وليس ضمانًا**: لا يمكن إرساله إذا انقطع الاتصال، ولا يملك firmware رسالة تأكيد أو مهلة توقف مستقلة.

ابدأ والروبوت مطفأ والعجلات مرفوعة. لا تستخدم الجسر لاختبار الحركة قرب أشخاص أو حيوانات أو سلالم أو ممتلكات. أبقِ مفتاح فصل الطاقة في متناولك، وافصل طاقة المحركات عند أي سلوك غير متوقع. تفاصيل القيود في [السلامة والاختبار](../docs/SAFETY_AND_TESTING.md).
